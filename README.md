# APETCTL (Advanced PET Control)

Это клон контроллера, управляющего станком, преобразующим ленту, нарезанную из PET-бутылок, в филамент, пригодный для 3D печати.

Исходный проект:
* [PETCTL](https://github.com/mvbasov/PETCTL) 

Здесь представлен оптимизированный код с упором на производительность и стабильность.

### Основные изменения в коде:

1. **Отказ от тяжелых библиотек для двигателя:** Полностью удалена библиотека `GyverStepper`. Управление шаговым двигателем переведено на прямое манипулирование регистрами **Timer 1**. Это позволило достичь плавности хода без "заиканий" на скоростях выше 5.1 мм/сек.
2. **Использование LUT-таблиц (Look-Up Table):** Все критические вычисления (температура и периоды шагов двигателя) переведены на предрассчитанные таблицы в `PROGMEM`. Это исключило использование тяжелой математики с плавающей точкой (`float`) в прерываниях.
3. **Многозадачность на таймерах:** 
   - **Timer 1 (16-бит):** Одновременно генерирует прецизионные шаги мотора и программный ШИМ для нагревателя (30 Гц).
4. **Повышенная отказоустойчивость:**
   - Внедрен аппаратный **Watchdog** (сторожевой таймер), предотвращающий зависание станка.
   - Добавлен визуальный "индикатор жизни" (вращающийся спиннер) для контроля работы основного цикла `loop()`.
   - Реализована аппаратная блокировка: при срабатывании защиты или зависании прерывания останавливаются, мгновенно обесточивая нагреватель и мотор.
5. **Плавный разгон (Acceleration):** Реализована логика мягкого старта мотора, что предотвращает обрыв тонкой ПЭТ-ленты при начале протяжки. В отличие от библиотечной функции из за перехода на управление мотором по прерыванию таймера на скоростях близких к максимальным разгон стал плавным.
6. **Контроль метража:** Добавлена поддержка второго энкодера (датчик пройденного пути). Теперь на OLED отображается точная длина полученного филамента в меетрах, также скорость отображается в двух вариантах
от энкодера длины прутка и планируемая расчитанная через шаги, редуктор, и диаметр катушки.
7. **Арифметика** Полностю бурана арифметика с плавающей точкой.
8. **Дисплей:** Переработана компановка визуальных элементов. Флаги состояний теперь все слева в одной колонке, далее измеренные параметры температуры, скорости, протянутого прутка. Слева запланированные занчения температуры, скорости.
9. **Код работы с дисплеем:** Удалена библиотека длы работы с OLED диспреем. Написаны собственные функции вывода на дисплей.
10. **IDE:** Сборка переведена на платформу platformio. Код разделен на несколько файлов.
11. **Энкодер Интерфейса:** Удалена библиотека работы с энкодером. Энкодер переведен на рботу через прерывания INT0 INT1 с фильтрацией ложных срабатываний.
